# ตรวจสอบยา · AI Pill

เว็บแอปตรวจสอบยาสำหรับผู้ใช้ทั่วไปและผู้สูงอายุ เปิดแล้วใช้ได้ทันที ไม่ต้องสมัครสมาชิก
รองรับภาษาไทย อังกฤษ และจีน

> ⚠️ ข้อมูลในแอปใช้ประกอบการตัดสินใจเบื้องต้นเท่านั้น ไม่ใช้แทนคำวินิจฉัยของแพทย์หรือเภสัชกร

## วิธีรัน

ไม่ต้อง build ใช้ไฟล์ static ได้เลย

```bash
python3 -m http.server 8000
```

แล้วเปิด <http://localhost:8000>. กล้องและไมโครโฟนต้องเปิดผ่าน `https://` หรือ `localhost` เท่านั้น
นำขึ้น GitHub Pages, Netlify หรือ static hosting ใดก็ได้

**โหมด AI:** กดปุ่ม ⚙️ แล้วใส่ Gemini API Key (โมเดลเริ่มต้น `gemini-3.8-flash` เปลี่ยนได้)
ถ้าไม่ใส่คีย์ แอปจะทำงานในโหมดสาธิต: การวิเคราะห์ภาพใช้ข้อมูลจำลองและมีป้ายบอกชัดเจน
ส่วนการค้นหา การระบุเม็ดยา การสแกนบาร์โค้ด และการตรวจยาตีกันจากฐานข้อมูล ทำงานได้ครบโดยไม่ต้องใช้คีย์
การเรียก AI หมดเวลาใน 45 วินาที และกดยกเลิกได้ตลอด

## สิ่งที่ทำตามโจทย์

| โจทย์ | การออกแบบ |
|---|---|
| **ลดขั้นตอน** | หน้าแรกมีปุ่มหลักขนาดใหญ่ 3 ปุ่มอยู่กลางจอ ไม่มีการล็อกอิน ถ้าพิมพ์ชื่อยาหรือชื่อการค้าตรงทุกตัวอักษร ระบบจะเปิดหน้ารายละเอียดทันที ถ้าตรงแค่บางส่วนจะแสดงเป็นรายการให้เลือก ปุ่มย้อนกลับของเบราว์เซอร์ใช้ได้ทุกหน้า |
| **Accessibility** | ตัวอักษรใหญ่กว่าค่าตั้งต้นของเบราว์เซอร์ 12.5% (18px เมื่อเบราว์เซอร์ตั้งไว้ 16px) ปรับได้ 4 ระดับ (ก− / ก+) และยังคงขนาดที่ผู้ใช้ตั้งไว้ในเบราว์เซอร์ มีโหมดคอนทราสต์สูง (ดำ/ขาว/เหลือง) ค่าคอนทราสต์ผ่าน WCAG AA ทุกจุด และข้อความหลักผ่าน AAA ปุ่มกดได้ไม่น้อยกว่า 48px (ปุ่มหลัก ~58px) มีค้นหาด้วยเสียง 🎤 และอ่านออกเสียง 🔊 ใช้ฟอนต์ Sarabun ที่อ่านภาษาไทยง่าย รองรับ screen reader |
| **3 เส้นทางค้นหา** | ① ระบุเม็ดยา: ถ่ายรูปให้ AI ดู หรือเลือกรูปร่าง/สี/ตัวอักษรบนเม็ด ② สแกนบาร์โค้ด / QR / ถ่ายรูปซองยา ③ พิมพ์หรือพูดชื่อยา |
| **ลำดับข้อมูลในหน้ารายละเอียด** | ชื่อสามัญ (ตัวใหญ่) และชื่อการค้า → ภาพของคุณเทียบกับภาพอ้างอิง → สรรพคุณ → วิธีใช้ → ข้อควรระวัง → ผลข้างเคียง → อันตราย/ห้ามใช้ → อาการที่ต้องพบแพทย์ทันที → ตรวจวันหมดอายุ → แหล่งอ้างอิง |
| **รหัสสี** | 🟢 เขียว = ข้อมูลทั่วไป · 🟠 ส้ม = ควรระวัง (เช่น ห้ามกินคู่กับนม, ทำให้ง่วง) · 🔴 แดง = อันตราย/ห้ามใช้/ยาหมดอายุ/ยาความเสี่ยงสูง ทุกสีมีไอคอนและข้อความกำกับ ไม่ได้สื่อความหมายด้วยสีอย่างเดียว |
| **Trust & Safety** | แถบฉุกเฉินบนหน้าแรก “แพ้ยารุนแรงให้พบแพทย์ทันที” กดโทร 1669 / 1367 ได้ทันที ทุกหน้ายาแสดงแหล่งอ้างอิง วันที่ตรวจทาน และลิงก์เว็บไซต์ อย. ข้อมูลจากฐานข้อมูลกับข้อมูลที่ AI สร้างแยกกันชัดเจนด้วยป้าย “ยังไม่ได้ยืนยัน” |
| **ป้องกันความผิดพลาด** | ค้นหาทนต่อการพิมพ์ผิด มี “คุณหมายถึง… หรือไม่?” (รวมการพิมพ์วรรณยุกต์ไทยผิด) ชื่อยาที่คล้ายกัน เช่น Atorvastatin หรือ Esomeprazole จะไม่ถูกเปิดเป็นยาอีกตัวโดยอัตโนมัติ คำกว้าง ๆ เช่น “ยาเบาหวาน” แสดงเป็นตัวเลือกเท่านั้น โหมดสาธิตและผล AI ที่ไม่มั่นใจมีป้ายสีส้ม ไม่ใช้สีเขียว ถ้าสแกนไม่เจอหรือ AI ไม่มั่นใจ จะแนะนำให้ถ่ายใหม่ในที่สว่าง พิมพ์ชื่อแทน ระบุจากรูปร่าง หรือปรึกษาเภสัชกร หน้าระบุเม็ดยาเตือนว่ายาต่างชนิดอาจหน้าตาเหมือนกัน ลิงก์จาก QR ที่ไม่ใช่โดเมน อย. จะมีคำเตือนก่อนเปิด |
| **ตรวจยาตีกัน** | เพิ่มยาได้หลายตัว (พิมพ์/พูด/เพิ่มจากหน้ายา) ตรวจคู่ยาที่ตีกันได้ 15 คู่ และตรวจยาซ้ำซ้อน เช่น Sara + Tylenol = พาราเซตามอลซ้ำ หากไม่พบ ระบบจะแจ้งว่า “ไม่พบในฐานข้อมูล” ไม่เคยบอกว่า “ปลอดภัย” ยาที่ไม่อยู่ในฐานข้อมูลให้ AI ตรวจเพิ่มได้ |

ฟีเจอร์เพิ่มเติมจากต้นฉบับ: AI อ่านฉลากผ่านถุงซิปล็อก นับจำนวนเม็ด และอ่านวันหมดอายุ
รองรับปี พ.ศ. ทั้งแบบ 4 หลักและ 2 หลัก (2570 / 70 → 2027) และแจ้งเตือนสีแดงเมื่อยาหมดอายุ

## โครงสร้างไฟล์

```
index.html        โครงหน้า, แถบเครื่องมือการเข้าถึง, dialog ตั้งค่า/ปรึกษาเภสัชกร
css/styles.css    ธีมปกติ + คอนทราสต์สูง, รหัสสี safe / warn / danger
js/i18n.js        ข้อความ UI 3 ภาษา
js/drugs.js       ฐานข้อมูลยาตัวอย่าง 12 รายการ + ปฏิกิริยาระหว่างยา (aliases = ชื่ออื่นของยาตัวนั้น, categories = คำกว้าง ๆ ที่ใช้แค่แนะนำ)
js/app.js         router, ค้นหา, ระบุเม็ดยา, สแกนบาร์โค้ด, Gemini, ตรวจยาตีกัน
```

การตั้งค่าอยู่ที่ `CONFIG` ด้านบนของ `js/app.js`
- `pharmacistChatUrl`: ใส่ลิงก์แชทเภสัชกรจริง เช่น LINE OA หรือบริการ telepharmacy ถ้าไม่ใส่ ปุ่ม “ปรึกษาเภสัชกร” จะแสดงร้านยาใกล้ฉัน, 1367 และ 1669
- `defaultModel`, `fdaUrl`, `emergencyTel`, `poisonTel`

## ก่อนใช้งานจริง (สำคัญ)

1. **ฐานข้อมูลยาเป็นตัวอย่าง** สรุปจากเอกสารกำกับยามาตรฐาน **ต้องให้เภสัชกรตรวจทาน** และควรเชื่อมกับแหล่งข้อมูลทางการ เช่น ฐานข้อมูลผลิตภัณฑ์ของ อย. หรือบัญชียาของโรงพยาบาล
2. **ภาพอ้างอิงเป็นภาพประกอบ (SVG)** ไม่ใช่ภาพถ่ายจริง และมีป้ายบอกในแอป ถ้ามีภาพถ่ายจริงจากแหล่งทางการ ให้ใส่ในช่อง `photo` ของยาแต่ละตัว
3. **บาร์โค้ด:** ยังไม่มีรหัส EAN จริงในฐานข้อมูล ให้เพิ่มในช่อง `barcodes: []` ตอนนี้ระบบอ่านชื่อยาและเลขทะเบียนตำรับยาที่อยู่ใน QR ได้
4. **API Key อยู่ในเบราว์เซอร์:** เหมาะกับต้นแบบเท่านั้น ระบบจริงควรเรียก Gemini ผ่าน backend/proxy ของตัวเอง
5. **รองรับตามเบราว์เซอร์:** การค้นหาด้วยเสียงใช้ Web Speech API (Chrome/Edge/Safari) สแกนบาร์โค้ดใช้ `BarcodeDetector` ถ้ามี ถ้าไม่มีจะโหลด ZXing 0.21.3 จาก CDN พร้อมตรวจ SRI hash (`CONFIG.zxingIntegrity`) ถ้าเปลี่ยนเวอร์ชันต้องอัปเดต hash ด้วย

**English summary:** A no-login, senior-friendly medicine checker (Thai/English/Chinese). It has three big entry points (pill identifier, barcode/package scan, type-or-speak search), adjustable large text, a high-contrast mode, voice search and read-aloud. Detail pages are colour-coded green/orange/red (always with icons and text), with emergency call buttons, sources, and clear "AI – unverified" labelling. Typo-tolerant "did you mean" search, fallback guidance when a scan fails, expiry checking with Buddhist-era years, and a drug interaction checker with duplicate-ingredient detection. Static files, no build. Gemini is optional; without a key the photo analysis runs in demo mode. The sample drug database must be reviewed by a pharmacist before real use.
